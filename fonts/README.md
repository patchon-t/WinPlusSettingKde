Drop font files (.ttf / .otf) here and the app loads them at startup.

For the exact Windows 11 look, copy `SegUIVar.ttf` (Segoe UI Variable) from
`C:\Windows\Fonts` on a Windows install you own. It's Microsoft's font and
can't be redistributed, so it's gitignored.

Free alternatives that also work: Selawik (Microsoft's open Segoe fallback), Inter.
